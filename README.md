# DIGIX – Freelance Digital Agency Project

![DIGIX Cover](images/digix-logo-white.png)

This repository contains a premium, high-end digital agency website that I developed as a freelance project for **DIGIX**, a full-service digital transformation company. 

The primary goal of this project was to create a striking, immersive digital experience that showcases their cinematic video production, graphic design, content creation, and data-driven marketing services.

## 🚀 Project Highlights

- **Cinematic Dark Mode UI**: A striking `#000000` pure-black foundation with glowing neon orange and cyan accents to match the agency's brand identity.
- **Interactive Glassmorphism**: Custom-built frosted-glass modals (with `backdrop-filter: blur()`) to display service offerings in a modern, app-like interface.
- **Advanced Scroll Animations**: Elements dynamically fade, rotate, and scale seamlessly as users scroll down the page, creating a highly engaging user experience.
- **Fully Responsive Architecture**: Flawless layout scaling from ultra-wide 4K monitors down to mobile devices. Includes custom mobile touch-swipe carousels for the Team section.
- **Interactive Particle Canvas**: A high-performance, mouse-reactive particle background system built entirely from scratch in native HTML5 Canvas.

## 🎨 Design Aesthetics

The design system was heavily focused on a premium, high-tech aesthetic:
- **Primary Colors**: Agency Orange (`#f1593a`), Cyber Cyan (`#00e5ff`), Pitch Black (`#000000`).
- **Typography**: *Helvetica Compressed* was used for massive, cinematic headings, while *Helvetica Neue* was utilized for clean, readable body copy.

## 🛠️ Technology Stack

This project was built entirely with native web technologies to ensure maximum performance without relying on heavy frameworks:
- **HTML5**: Semantic, accessible markup.
- **CSS3 (Vanilla)**: Advanced CSS Grid, Flexbox, dynamic `clamp()` typography, CSS Variables, and keyframe animations.
- **JavaScript (Vanilla)**: Lightweight custom scripts for interactive modals, dynamic scroll tracking, and the mathematical physics engine for the canvas particle system.
